# Bengal Unfolded

> A bilingual historical storytelling project about Bengal's journey through memory, identity, struggle, and transformation.

## Overview

Bengal Unfolded is a digital project that presents the history of Bengal and Bangladesh in a more connected, human, and accessible way. It aims to help readers explore major historical moments not as isolated facts, but as part of a larger journey of people, language, resistance, and identity.
