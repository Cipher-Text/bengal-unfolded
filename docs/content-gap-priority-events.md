# Priority Event Gap Backlog

Date: 2026-06-15

This document converts the current repo audit into an actionable backlog of major missing event chapters.

Scope:

- identifies historically significant missing event pages
- proposes concrete slugs
- maps each candidate to existing topic hubs
- points to repo-local source anchors already present in `content/resources`

This is a planning document only. It does not change schema, validators, or content data.

## Audit summary

The archive already covers the main Bengal/Bangladesh historical spine well. The largest remaining gaps are:

- transition chapters that connect major periods to the next turning point
- first-class treatment of high-impact constitutional or justice events currently buried inside broader pages
- replacement of one generic placeholder event with concrete late-colonial political chapters
