# Quiz source check (Liberation War pool)

Date: 2026-11-24. Scope: the 40 draft questions `lib-001` to `lib-040`. Four agents checked each question against open web sources (Banglapedia, Wikipedia, Daily Star, Dhaka Tribune, Dawn, TBS and others); results were merged and the questions edited by the lead.

**Result: 36 questions are READY for Bengali review and then publishing; 4 are on HOLD and must not be published until fixed.** Nothing has been published: every question is still `status: draft`.

How each question was judged:
1. Is the intended correct answer stated by an open source (SUPPORTED), only an author's framing (INTERPRETIVE), contradicted, contested, or not found?
2. Is every wrong option clearly wrong?
3. Does every sentence of the explanation hold (dates, numbers, names)?

Where a claim is contested or sources differ (dates, first broadcasts, talks, tribunal demands), the question was reworded to the documented fact or the explanation says that sources differ.

## Limits

- Wikipedia was the main source for the second and third groups; Banglapedia and archival pages were opened for only some questions. Several Wikipedia pages were read only in part (first 100,000 characters). This is a good-faith check, not a scholarly one.
- Many cited resources in `resourceIds` are books, novels or compilations with no URL, so they could not be checked. The verification sources are listed below instead; the in-product "Read the story" link goes to the chapter, not to the resources.
- Some details (1 March postponement, 10 January 1972 return) rest on Daily Star or search summaries rather than a fully opened page.
- Bengali text was updated alongside every English change and still awaits a fluent reader.
